# 示例账单数据

这里的两个 CSV 是**程序生成的合成数据**，不是任何人的真实账单。

| 文件 | 编码 | 说明 |
|---|---|---|
| `微信支付账单_示例.csv` | UTF-8（带 BOM） | 模仿微信支付账单导出格式，11 列 |
| `支付宝交易明细_示例.csv` | GBK | 模仿支付宝交易明细导出格式，13 列 |

文件的**前导区块文案、列名、列顺序、编码都与真实导出一致**，商户名统一使用知名品牌
或虚构店铺名，因此可以用来验证「导入 CSV」功能能否正确识别格式与自动分类。

- 交易时间范围：2025-05 ~ 2026-04
- 微信：62 行数据（含收入、支出与中性交易）
- 支付宝：68 行数据（含支出、收入与「不计收支」类，用于验证跳过逻辑）

导入方式：运行 `python main_gui.py`，在「交易管理」选项卡点击 **导入CSV** 后选择文件。

> 真实账单请勿提交到公开仓库。
