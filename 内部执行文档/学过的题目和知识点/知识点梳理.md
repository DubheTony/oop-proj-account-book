## 第一章：面向对象简介与UML应用（作业1）

### 1.1 面向对象核心概念
| 知识点 | 说明 |
|--------|------|
| 四大核心概念 | 封装、抽象、继承、多态 |
| OOP 缩写 | Object-Oriented Programming |
| 与面向过程的区别 | 更好的复杂度管理、更高的代码复用率、更易于维护 |
| 编程范式对比 | 面向过程（数据+函数）、函数式（数据转换）、面向对象（对象+方法） |

### 1.2 封装
| 知识点 | 说明 |
|--------|------|
| 封装目的 | 保护内部数据免受外部直接访问 |
| 黑盒原理 | 对应"抽象"概念 — 隐藏内部实现细节 |
| 数据捆绑 | 将数据和操作数据的方法捆绑在一起 |

### 1.3 继承
| 知识点 | 说明 |
|--------|------|
| 继承定义 | 一个类从另一个类继承属性和方法 |
| UML 表示 | 实线带空心三角形箭头 |
| is-a 关系 | 继承表达的是 is-a 关系 |
| 代码复用 | 从现有类创建新类，无需重新编写所有代码 |

### 1.4 多态
| 知识点 | 说明 |
|--------|------|
| 多态定义 | 同一接口可以有不同的实现 |
| 表现形式 | 调用不同子类的同一方法产生不同行为 |

### 1.5 UML 基础
| 知识点 | 说明 |
|--------|------|
| 主要图表类型 | 类图、序列图、用例图（不含流程图） |
| 类图可见性标记 | `+` 公共(Public)、`-` 私有(Private)、`#` 受保护(Protected)、`~` 包内可见 |
| 用例图 | 捕捉用户需求和系统功能，称为用户的"功能"视角 |
| 序列图 | 展示对象间的消息传递（交互/信息流），随时间变化 |
| 活动图 | 帮助理解系统行为 |
| 部署图 | 描述系统的硬件配置及其上运行的软件模块 |
| UML 适用性 | 不仅适用于大型项目，小型项目也可使用 |
| UML 开发阶段 | 需求收集分析 → 设计（不含编码、市场调研） |
| UML 好处 | 提升沟通效率、提高设计质量、增强早期错误检测、帮助识别设计缺陷 |

### 1.6 Python 类基础
| 知识点 | 说明 |
|--------|------|
| `__init__` 方法 | 初始化对象的属性 |
| 创建对象 | `a = MyClass()` |
| 方法定义 | 第一个参数约定为 `self` |
| 调用方法 | 不需要手动传入 self |

## 第二章：递归基础知识（作业2）

### 2.1 递归核心概念
| 知识点 | 说明 |
|--------|------|
| 递归定义 | 函数直接或间接地调用自身 |
| 递依赖机制 | 函数调用 + 调用栈 |
| 两大条件 | 基线条件(base case) + 递归条件(recursive case) |
| 递归与迭代 | 可以互相转化 |

### 2.2 调用栈
| 知识点 | 说明 |
|--------|------|
| 调用栈管理 | 由编程语言和操作系统管理 |
| 数据结构 | LIFO（后进先出），非 FIFO |
| 操作 | push() 和 pop()（一端操作，该端为栈顶端） |
| Frame Object | 包含：返回地址、传递参数、本地变量 |
| 递归执行流程 | 记住调用位置 → 创建新帧 → 返回时交还控制权 |

### 2.3 堆栈溢出
| 知识点 | 说明 |
|--------|------|
| 原因 | 调用栈过高 |
| 自调用不返回 | 导致调用栈快速增长 |
| Python 限制 | 不允许递归调用超过预设的最大深度 |
| 与系统崩溃 | 堆栈溢出不必然导致系统崩溃 |

### 2.4 递归设计要点
| 知识点 | 说明 |
|--------|------|
| 基线条件重要性 | 防止无限递归导致栈溢出，确保最终结束 |
| 递归条件 | 函数向基线条件靠近的自我调用 |
| 递归前后 | 递归调用前的代码 和 递归调用后的代码 |
| 转换方法 | 任意递归代码可通过循环+栈转换为迭代 |
| 效率 | 递归不是总比迭代更有效率 |

## 第三章：典型递归算法（作业3）

### 3.1 头尾分割技术
| 知识点 | 说明 |
|--------|------|
| 基本方法 | 取出第一个元素作为"头"，剩余作为"尾" |
| 数组求和 | head=3, tail=[4,5,6]（头是单个元素值） |
| 字符串反转 | head='h', tail='elloworld'（头是单个字符） |
| 回文判断 | 头尾各取一个字符："a"和"a"，中间"bb" |

### 3.2 数组求和递归
| 知识点 | 说明 |
|--------|------|
| 基线条件 | 列表长度为 0 或列表为空 |
| 递归条件 | 数组不为空或长度不为 0 |

### 3.3 字符串反转递归
| 知识点 | 说明 |
|--------|------|
| 基线条件 | 字符串为空或仅含 1 个字符 |
| 递归条件 | 字符串长度大于 1 |

### 3.4 回文判断递归
| 知识点 | 说明 |
|--------|------|
| 基线条件 | 字符串长度为 0 或为 1 |
| 递归条件 | 头尾字符相同 |

### 3.5 洪泛填充递归
| 知识点 | 说明 |
|--------|------|
| 基线条件 | 当前像素颜色≠原颜色 或 到达图片边缘 |
| 递归条件 | 四邻域像素（上下左右）颜色为原颜色且在图内 |

## 第四章：面向对象封装（作业7）

### 4.1 类与对象
| 知识点 | 说明 |
|--------|------|
| 创建对象 | `a = MyClass()` |
| 动态添加属性 | `a.x = x`（不影响同一类创建的其他对象） |
| 类属性 vs 实例属性 | 类属性影响所有实例？— 动态为类添加属性不影响已创建对象 |
| `__init__` | 初始化函数，非必须 |
| `__new__` | 构造函数，在 `__init__` 前调用，负责在内存中开辟对象空间 |

### 4.2 方法定义
| 知识点 | 说明 |
|--------|------|
| self 参数 | 方法的第一个参数约定为 self |
| 调用时 | 不需要显式传入 self |
| get/set 模式 | 用于保护私有属性 |

### 4.3 访问控制
| 知识点 | 说明 |
|--------|------|
| Python 的公开性 | 理论上所有属性和方法都是 public |
| 单下划线 `_` | Protected 约定，不建议从外部访问（非强制） |
| 双下划线 `__` | Private 约定，触发 name mangling（非强制） |
| Name Mangling | 在属性名前加 `_类名`，内部访问时自动还原，外部需自行处理 |

### 4.4 docstring
| 知识点 | 说明 |
|--------|------|
| 书写方式 | 单行或多行（用 `'''` 或 `"""`） |
| 查看方法 | `help()` 函数 |
| 性质 | 非强制，有助于自文档化 |
| 最佳实践 | 是良好的编程实践 |

### 4.5 模块导入
| 知识点 | 说明 |
|--------|------|
| 导入方式 | `import A`、`import A.B`、`from A import B`、`from A import *` |

## 第五章：面向对象继承（作业8）

### 5.1 继承基础
| 知识点 | 说明 |
|--------|------|
| 父类/子类 | 被继承的叫父类，继承的叫子类 |
| Python 语法 | `class Child(Parent):` |
| 所有类的基类 | object |
| 内置类继承 | 大部分内置类(list, set, dict, file等)均可被继承 |

### 5.2 Overriding（方法覆写）
| 知识点 | 说明 |
|--------|------|
| 定义 | 在子类中以相同方法名改写父类方法 |
| 目的 | 改变现有类的行为 |
| 不需要特殊语法 | Python 直接支持 |
| 注意事项 | 保持命名清晰、风格一致、尽量用 super、避免覆写核心/魔术方法 |

### 5.3 super 函数
| 知识点 | 说明 |
|--------|------|
| 作用 | 提供调用父类方法的便利机制 |
| 调用位置 | 可在子类的任意方法中调用，可发生在方法的任意位置 |
| super() 返回 | 一个代理对象（不是父类本身） |

### 5.4 多继承
| 知识点 | 说明 |
|--------|------|
| Python 支持 | 原生支持多继承 |
| 兼容性问题 | 不一定会引起继承链混乱 |
| Mixin | 一种实现多继承的方法，部分不表达 is-a 关系 |
| 初始化问题 | 引入初始化多个父类的需求 |

### 5.5 MRO 与 Diamond Problem
| 知识点 | 说明 |
|--------|------|
| MRO | Method Resolution Order（方法解析顺序） |
| 查看方式 | `__mro__` 魔术变量 |
| 算法演进 | 深度优先 → 广度优先 → C3 线性化 |
| Diamond Problem | 菱形继承链导致某父类可能被多次初始化 |
| 解决方式 | MRO + 统一关键字参数设计 |

### 5.6 多继承中的关键字参数设计
| 知识点 | 说明 |
|--------|------|
| 设计原则 | 提前规划，使用关键字参数统一初始化 |
| 子类职责 | 为父类需要的参数和自身参数设置默认值 |
| 好处 | 实现统一的 super 调用链 |

## 第六章：面向对象多态（作业9）

### 6.1 多态基础
| 知识点 | 说明 |
|--------|------|
| 多态定义 | 调用不同子类的同一方法产生不同行为 |
| 动态分派 | 运行时根据对象真实类型决定执行哪个方法 |

### 6.2 Method Overriding（方法覆写）
| 知识点 | 说明 |
|--------|------|
| 含义 | 在子类中以相同的方法名改写父类方法 |
| 签名匹配 | 方法名、参数列表、返回值要与父类一致 |
| 实现机制 | 类型判断 + 方法名匹配 + 方法签名匹配 + 动态分派 |

### 6.3 函数重载（Python不支持）
| 知识点 | 说明 |
|--------|------|
| Python 的态度 | 不直接支持函数重载 |
| 替代方案 | 利用参数默认值、利用关键字参数/字典参数 |

### 6.4 鸭子类型（Duck Typing）
| 知识点 | 说明 |
|--------|------|
| 定义 | 关注对象的方法/属性而非对象类型 |
| 依赖机制 | 对象是否支持特定名字的属性或方法 |
| 类型安全 | 安全问题在运行时才表现 |
| 使用注意 | 对接口异常做说明、采用类型提示、关键部分引入 typing |

### 6.5 抽象基类（ABC）
| 知识点 | 说明 |
|--------|------|
| 定义 | 定义一组子类均需实现的方法和属性 |
| abc 模块 | 提供 `@abstractmethod`、`@abstractproperty`、`@classmethod` 装饰器 |
| `__abstractmethods__` | frozenset，记录抽象方法集合 |
| 子类要求 | 抽象方法必须在子类中实现 |

| 多变量/多重循环 | 支持 |

### 7.5 字典（Dictionary）
| 知识点 | 说明 |
|--------|------|
| 排序 | 元素不遵循下标排序（按 key 哈希） |
| 可变性 | 可变数据结构 |
| 嵌套 | 支持嵌套字典 |
| id 变化 | `\|` 运算符 和 `.copy()` 返回新字典（不同 id） |
| 字典推导 | `{key: val for ... in ... if ...}` |

## 第八章：文件读写操作（作业5）

### 8.1 文件操作基础
| 知识点 | 说明 |
|--------|------|
| 不需要导入 | Python 内置 open()，不需导入 file 模块 |
| open() 返回值 | 返回文件对象（不是整数） |
| 带 `+` 模式 | 支持读写 |
| 带 `b` 模式 | 支持操作二进制文件 |
| Append 模式 | 追加而非覆盖 |
| 文件属性 | `f.name` 返回文件名，`f.mode` 返回访问模式 |

### 8.2 文件指针与读写
| 知识点 | 说明 |
|--------|------|
| `f.tell()` | 返回当前文件指针位置 |

| `f.write()` | 接受一个待写入对象为参数 |
| `f.seek()` | 移动文件指针 |

### 8.3 文件关闭
| 知识点 | 说明 |

| `f.close()` | 完成读写后一定要关闭 |

### 8.4 JSON 模块

### 8.5 CSV 操作

|--------|------|

| numpy 方法 | `loadtxt()` 读取，`savetxt()` 写入 |
| pandas 方法 | `read_csv()` 读取，`to_csv()` 写入 |

### 8.6 其他文件操作
| 知识点 | 说明 |
|--------|------|
| 文件重命名 | `os.rename()` |
| 文件删除 | `os.remove()` |
| SQLite3 操作流程 | connect → cursor → execute → close |

## 第九章：程序异常处理（作业6）

### 9.1 异常处理基础
| 知识点 | 说明 |
|--------|------|
| 异常处理目的 | 处理程序运行时的错误（非编写时错误） |
| 关键字 | try、except、else、finally |

### 9.2 常见异常类型
| 异常类型 | 触发场景 |
|----------|----------|
| `TypeError` | 操作类型不匹配（如字符串+数字、math.sin("6pi")） |
| `ValueError` | 值错误（类型正确但值不合适） |
| `IndexError` | 用超出序列长度的下标访问 |
| `KeyError` | 用字典中不存在的键访问 |
| `AttributeError` | 访问对象中不存在的属性 |
| `NameError` | 访问未定义的变量 |
| `ZeroDivisionError` | 数字除以 0 |
| `IOError` | 输入输出异常 |

### 9.3 异常处理语法
| 知识点 | 说明 |
|--------|------|
| `except` 裸用 | 捕获所有异常 |
| `except 类型` | 捕获指定异常 |
| `except 类型 as e` | 捕获并获取异常对象 |
| `except (类型1, 类型2)` | 捕获多种异常 |

### 9.4 自定义异常
| 知识点 | 说明 |
|--------|------|
| 继承 | 通常继承 Exception 类 |
| 构造 | 不需要一定重写构造函数 |
| 参数 | 可自定义参数、处理上下文信息 |

### 9.5 raise 关键字
| 知识点 | 说明 |
|--------|------|
| 用途 | 主动抛出异常 |
| 异常类型 | 可用内置异常类或自定义异常类 |
| 传参 | 可向异常类传递参数 |
