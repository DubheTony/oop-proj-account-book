### 2.1 Suggestion（C 负责）

```python
from dataclasses import dataclass

@dataclass
class Suggestion:
    """一条可操作的建议。所有数字由策略根据实际数据计算，不使用模板句。"""
    priority: int          # 1=高优(必须改) / 2=中优 / 3=低优
    impact_amount: float   # 执行此建议预计每月可改善的金额
    category: str          # 关联的支出类别
    description: str       # 由策略生成的描述文本，含具体数字
```

### 2.2 DimensionDetail（D 负责）

```python
@dataclass
class DimensionDetail:
    """单一诊断维度的评分与建议"""
    strategy_name: str     # 策略名，如 "储蓄率诊断"
    score: float           # 0~100 得分
    level: HealthLevel     # 该维度等级
    suggestion: Suggestion # 该维度的建议（可为 None 表示无需建议）
```

### 2.3 DiagnosisReport（D 负责）

```python
@dataclass
class DiagnosisReport:
    """诊断报告。suggestions 按 impact_amount 降序排列。"""
    overall_level: HealthLevel
    overall_score: float                       # 0~100 综合评分
    dimensions: list[DimensionDetail]          # 各维度明细
    suggestions: list[Suggestion]              # 按 impact_amount 降序
```

### 2.4 MonthlyPlan（E 负责）

```python
@dataclass
class MonthlyPlan:
    """储蓄倒推的结果"""

    extra_cut_needed: float                    # 每月需额外削减的金额
    category_cuts: dict[str, float]            # 各类别建议削减金额 {"餐饮": 300, "娱乐": 200}
```

## 三、领域实体

### 3.1 Transaction（C 负责）

```python
from dataclasses import dataclass
from datetime import date

@dataclass
class Transaction:
    amount: float
    type: str              # "收入" 或 "支出"
    category: str          # "餐饮" / "交通" / "娱乐" / "学习" / "日用" / "其他" 等
    account: AccountType
    date: date
    note: str = ""

    def is_expense(self) -> bool:
        return self.type == "支出"

    def is_income(self) -> bool:
        return self.type == "收入"
```

### 3.2 Budget（C 负责）

```python
@dataclass
class Budget:
    category: str
    monthly_limit: float
    current_spent: float = 0.0

    def is_exceeded(self) -> bool:
        """是否超支"""
        return self.current_spent > self.monthly_limit

    def get_remaining(self) -> float:
        """剩余额度"""
        return self.monthly_limit - self.current_spent

    def add_expense(self, amount: float) -> None:
        """记录一笔支出"""
        self.current_spent += amount
```

## 四、策略接口

### 4.1 DiagnosticStrategy（D 负责接口定义，D 负责所有实现）

```python
from abc import ABC, abstractmethod

class DiagnosticStrategy(ABC):
    """
    诊断策略接口。
    每个实现封装一种诊断算法。
    """

    @abstractmethod
    def diagnose(
        self,
        transactions: list[Transaction],
        budgets: list[Budget]
    ) -> DiagnosisReport:
        """
        参数:
            transactions: 全部交易记录
            budgets:      全部预算记录
        返回:
            DiagnosisReport，其中 overall_score 为 0~100，
            overall_level 为该策略判定的等级
        """
        ...
```

**具体实现要求**：

| 策略 | 文件 | score 计算逻辑 |
|---|---|---|
| `SavingRateStrategy` | `strategies/saving_rate.py` | saving_rate = (总收入-总支出)/总收入。score = min(saving_rate/0.3 * 100, 100)。rate<0 → CRITICAL，rate<0.1 → WARNING，≥0.2 → HEALTHY |
| `CategoryOverrunStrategy` | `strategies/category_overrun.py` | 遍历 budgets，对每个超支类别：overrun_ratio = (已支出-限额)/限额。取最严重超支的类别评分。score = max(0, 100 - max_overrun*100)。无超支→HEALTHY |
| `ConsumptionStructureStrategy` | `strategies/consumption_structure.py` | 计算四维度占比：基础饮食(食堂+食材)、社交饮食(外卖+聚餐)、娱乐、学习。各维度与健康区间比较。健康区间：基础饮食≤25%，社交饮食≤15%，娱乐≤15%，学习≥5%。综合各维度偏差评分 |
| `CompositeDiagnosis` | `strategies/composite.py` | P1。初始化时传入 `[(strategy, weight), ...]`。diagnose() 并行运行全部子策略。overall_score = Σ(sub.score × weight)。overall_level 由 overall_score 映射：≥80→HEALTHY，50-79→WARNING，<50→CRITICAL。dimensions 和 suggestions 汇总所有子策略结果 |

### 4.2 BudgetRule（E 负责接口定义，E 负责所有实现，P1）

```python
class BudgetRule(ABC):
    """
    预算分配策略接口。
    根据收入和消费历史，计算各类别的建议预算。
    """

    @abstractmethod
    def allocate(
        self,
        income: float,
        history: list[Transaction]
    ) -> dict[str, float]:
        """
        参数:
            income:  月收入
            history: 历史交易记录（用于分析消费模式）
        返回:
            {"餐饮": 1500.0, "交通": 300.0, ...}
        """
        ...
```

**具体实现要求**：

| 策略 | 文件 | 逻辑 |
|---|---|---|
| `FixedBudgetRule` | `rules/fixed_budget.py` | 构造函数接收 `dict[str, float]` 或通过 `set_budget(cat, limit)` 逐个设置。allocate() 直接返回内部存储的阈值表 |
| `Rule503020` | `rules/rule_503020.py` | necessities=income×0.5, wants=income×0.3, savings=income×0.2。necessities 和 wants 进一步按历史各子类别占比拆分。savings 不映射到支出类别，仅作为储蓄目标标记 |

### 4.3 SavingsMethod（E 负责接口定义，E 负责所有实现，P1）

```python
class SavingsMethod(ABC):
    """
    储蓄方法接口。
    根据月收入和历史，生成储蓄节奏计划。
    """

    @abstractmethod
    def calculate(
        self,
        monthly_income: float,
        history: list[Transaction]
    ) -> SavingsPlan:
        ...
```

**具体实现要求**：

| 策略 | 文件 | 逻辑 |
|---|---|---|
| `FixedAmountMethod` | `methods/fixed_amount.py` | 构造传入 `monthly_amount`。52 周均分（周金额=月金额×12/52） |
| `Week52Method` | `methods/week52.py` | 构造参数 `base_amount=10, reversed=False`。标准版：第n周存 n×base。反向版：第n周存(53-n)×base。年总额=base×1378 |
| `PercentageMethod` | `methods/percentage.py` | 构造传入 `rate`（如 0.2）。月储蓄=income×rate。52 周均分 |

## 五、领域服务

### 5.1 SavingGoalCalculator（E 负责）

```python
class SavingGoalCalculator:
    """
    储蓄目标倒推计算器。
    根据目标金额和时间范围，逆推每月需储蓄金额，
    并根据 cut_ratios 分配削减建议到各类别。
    """

    def __init__(self):
        # 默认削减比例：弹性支出类别
        self._cut_ratios: dict[str, float] = {
            "餐饮": 0.40,
            "娱乐": 0.60,
        }

    def set_cut_ratio(self, category: str, ratio: float) -> None:
        """设置某类别的削减比例（0~1）"""
        self._cut_ratios[category] = ratio

    def calculate_plan(
        self,
        target: float,         # 储蓄目标金额
        months: int,           # 计划月数
        history: list[Transaction]
    ) -> MonthlyPlan:
        """
        1. 从 history 计算月均收入和月均支出 → 自然结余 = 月均收入-月均支出
        2. 所需月储蓄 = target / months
        3. 若所需月储蓄 <= 自然结余 → extra_cut_needed=0，目标可自然达成
        4. 否则 extra_cut_needed = 所需月储蓄 - 自然结余
        5. 按 cut_ratios 将 extra_cut_needed 分配到各类别
        6. 为每个需削减类别生成 Suggestion
        7. 若 history 不足 1 个月 → 抛出异常提示数据不足
        """
        ...
```

## 六、主控类

### 6.1 FinanceController（C 负责骨架，所有人接入）

```python
class FinanceController:
    """
    总协调器。持有所有数据和策略引用，对 GUI/CLI 提供统一 API。
    """

    def __init__(self):
        self._transactions: list[Transaction] = []
        self._budgets: list[Budget] = []
        self._alert_messages: list[str] = []

        # 策略引用（P0 必设，P1 可选）
        self.diagnosis_strategy: DiagnosticStrategy | None = None
        self.budget_rule: BudgetRule | None = None              # P1
        self.savings_method: SavingsMethod | None = None        # P1

        # 领域服务
        self.saving_calculator: SavingGoalCalculator = SavingGoalCalculator()

    # ========== 交易管理 ==========

    def add_transaction(self, t: Transaction) -> None:
        """保存交易 → 若为支出则更新对应 Budget → 检查超支 → 记录告警"""
        ...

    def import_csv(self, path: str) -> int:
        """
        解析 CSV 文件，返回成功导入的条数。
        CSV 列：date, amount, type, category, account, note
        空行和格式错误行跳过并 print 警告。
        """
        ...

    def get_transactions(self) -> list[Transaction]:
        return self._transactions.copy()

    # ========== 预算管理 ==========

    def set_budget(self, b: Budget) -> None:
        """添加或更新一个类别的预算"""
        ...

    def get_budgets(self) -> list[Budget]:
        return self._budgets.copy()

    def apply_budget_rule(self, income: float) -> dict[str, float]:
        """
        使用当前 BudgetRule 计算各类别建议预算（P1）。
        若 budget_rule 未设置则抛出异常。
        """
        if self.budget_rule is None:
            raise RuntimeError("BudgetRule 未设置")
        return self.budget_rule.allocate(income, self._transactions)

    # ========== 诊断 ==========

    def set_diagnosis_strategy(self, s: DiagnosticStrategy) -> None:
        self.diagnosis_strategy = s

    def generate_diagnosis(self) -> DiagnosisReport:
        """使用当前 diagnosis_strategy 生成诊断报告"""
        if self.diagnosis_strategy is None:
            raise RuntimeError("DiagnosticStrategy 未设置")
        return self.diagnosis_strategy.diagnose(self._transactions, self._budgets)

    # ========== 储蓄 ==========

    def set_budget_rule(self, r: BudgetRule) -> None:
        self.budget_rule = r

    def set_savings_method(self, m: SavingsMethod) -> None:
        self.savings_method = m

    def generate_saving_plan(self, target: float, months: int) -> MonthlyPlan:
        """使用 SavingGoalCalculator 生成储蓄倒推计划"""
        return self.saving_calculator.calculate_plan(target, months, self._transactions)

    def get_savings_plan(self, income: float) -> SavingsPlan:
        """使用当前 SavingsMethod 生成储蓄方法建议（P1）"""
        if self.savings_method is None:
            raise RuntimeError("SavingsMethod 未设置")
        return self.savings_method.calculate(income, self._transactions)

    # ========== 告警 ==========

    def get_alert_messages(self) -> list[str]:
        return self._alert_messages.copy()

    def clear_alerts(self) -> None:
        self._alert_messages.clear()
```

### 7.1 CSV 格式约定

```csv
date,amount,type,category,account,note
2025-03-15,35.5,支出,餐饮,微信,食堂午饭
2025-03-15,2000,收入,其他,银行卡,三月生活费
2025-03-16,89,支出,娱乐,支付宝,电影票
```

| 列 | 格式 | 说明 |
|---|---|---|
| date | YYYY-MM-DD | 交易日 |
| amount | 数字 | 金额 |
| type | "收入" 或 "支出" | 交易类型 |
| category | 字符串 | 原始类别，需经标准化 |
| account | WECHAT/ALIPAY/CASH/BANK_CARD | 支付账户 |
| note | 字符串 | 备注 |

## 九、模块依赖关系

```
models/          ← 无内部依赖（纯数据类）
    ↑
strategies/      ← 依赖 models/
rules/           ← 依赖 models/（P1）
methods/         ← 依赖 models/（P1）
    ↑
services/        ← 依赖 models/ + strategies/ + rules/ + methods/
    ↑
gui/             ← 依赖 services/（通过 FinanceController）+ models/
```

> **规则**：下层不依赖上层。models 不依赖任何业务模块。strategies/rules/methods 之间不互相依赖。
