# 个人财务管理系统功能说明

## 项目概述

一款个人财务管理桌面应用。
支持多账户（微信/支付宝/银行卡）收支记录、CSV账单导入、消费健康度诊断、预算管理和储蓄规划。

---

## 一、必须实现的功能

### 1. 数据功能

- 交易记录：金额、类型（收入/支出）、类别、支付账户、日期、备注
- 预算：类别、月度限额、已支出金额，支持超支判断
- 支付账户枚举：微信、支付宝、银行卡
- 建议值对象：含优先级、影响金额、关联类别、具体建议文本（一些由实际数据计算得出的数字）

### 2. 消费健康度诊断

采用 Strategy 模式实现三个诊断维度：

- 储蓄率：计算储蓄率 =（总收入-总支出）/ 总收入，低于阈值则告警
- 类别超支检查：遍历所有预算类别，检测超支情况并输出明细
- 消费结构分析（类似恩格尔系数）：分析基础饮食/社交饮食/娱乐/学习四个维度的占比，与健康消费区间比较
- 诊断结果统一输出为 DiagnosisReport，包含综合等级（健康/预警/严重）、各维度评分和具体建议

### 3. 储蓄目标倒推

- 输入目标金额和计划月数，根据历史收支数据逆推每月需储蓄额度
- 差额部分按可配置的削减比例分配到各类别（如餐饮40%、娱乐60%）
- 输出 MonthlyPlan：所需月储蓄、当前自然结余、需额外削减额、各类别削减建议

### 4. 预算超支预警

- 在录入支出时自动检查对应类别预算
- 超支时生成告警信息（只在首次超支时告警，避免重复）

### 5. CSV 账单导入

- 解析约五个月的微信/支付宝账单 CSV 文件
- 自动跳过空行和格式错误行，支持 YYYY-MM-DD 和 YYYY/MM/DD 日期格式
- 类别标准化：将 CSV 中类别名映射为标准类别（"餐饮"）

### 6. GUI 界面（PySide6）

- 主窗口：顶部下列四个选项卡切换，底部状态栏显示告警
- 交易录入页：表单录入 + 交易列表（支持按日期/类别/账户筛选）+ CSV 导入按钮
- 诊断报告页：综合评分展示（颜色标签）+ 各维度明细 + 按优先级分组的建议列表
- 预算设置页：预算列表（含进度条）+ 添加/修改预算功能
- 储蓄计划页：储蓄倒推计算 + 结果展示

## 二、看时间情况决定增加

### 1. 复合诊断

- 诊断子策略加权计算综合评分

### 2. 更多预算规则（2、3借鉴app store上热门记账软件功能）

- 用户手动设定各类别固定预算
- 50%必要支出、30%想要支出、20%储蓄，子类别按历史消费比例自动拆分

### 3. 更多储蓄方法

- 固定金额法：每月固定数额储蓄
- 52周存款法：第 n 周存 n×基数（如10元），分标准递增版和反向递减版，基数可调
- 比例法：每月按收入固定比例储蓄

### 4. 图表（matplotlib 嵌入 PySide6）

- 月度消费折线图：横轴为月份，纵轴为金额，总支出和总收入分别用不同颜色折线
- 类别饼图：当前月份的各类别支出占比
- 52周存款曲线图（如已实现52周储蓄方法）
